Redis
C (Native), C++ (only for minor inconveniences)
Redis a.k.a "Remote Dictonary Server" is a simpler implementation of a cache server. The data is stored in key-value format in the memory i.e. RAM itself. The distinguishing characteristics of Redis are high concurrency, automatic expiration and low latency.

RISC-V Benchmarking Framework (Ongoing)
C/C++, Python, RISC-V GNU Toolchain, Spike/gem5
I am currently working on a simulation-based benchmarking framework to evaluate custom RISC-V ISA extensions for accelerating transformer computational kernels on edge devices. The proposed modified RISC-V simulators will compare baseline execution against proposed custom instructions. The goal is to optimise dynamic instruction count and execution cycles.
